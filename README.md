# s21_projects

Проекты, разработанные в рамках обучения в Школе 21

## C

- [brick game v1.0](./brickgamev1) — игра "Тетрис" (CLI на ncurses)
- [brick game v2.0](./brickgamev2) — расширенная версия (несколько режимов)
- [decimal](./decimal) — реализация десятичного типа и операций
- [matrix](./matrix) — реализация матричных операций (determinant, inverse и т.д.)

## CPP

- [3d viewer](./3dviewer) — простой 3D-просмотрщик и демонстрация рендеринга
- [containers](./containers) — реализация базовых контейнеров (vector, map, set и т.д.)
- [matrixplus](./matrixplus) — объектно-ориентированная реализация матриц на C++
