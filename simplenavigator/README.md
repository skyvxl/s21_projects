# SimpleNavigator

Язык: Go

Кратко: консольное приложение для работы со взвешенными графами. Поддерживает обход в ширину и глубину, поиск кратчайших
путей, построение минимального остовного дерева, решение задачи коммивояжёра и сравнение алгоритмов её решения.

Зависимости: Go 1.27+

Запуск из каталога `simplenavigator`:

```sh
go run ./src/cmd/navigator
```

Выберите пункт `1` и нажмите Enter на запросе пути, чтобы загрузить пример из `data-samples/graph.txt`. Первая строка
файла содержит число вершин, следующие строки задают матрицу смежности. Экспорт через пункт `2` сохраняет граф в
`build/graph.dot`.

Сборка и тесты:

```sh
go build -o build/navigator ./src/cmd/navigator
go test ./...
```

Структура проекта:

```text
src/
├─ cmd/navigator/         # консольное меню
├─ s21_graph/             # модель графа, чтение файлов и экспорт в DOT
├─ s21_graph_algorithms/  # алгоритмы на графах
├─ s21_queue/             # очередь
├─ s21_stack/             # стек
└─ tsp_comparison/        # сравнение алгоритмов коммивояжёра
data-samples/             # пример графа
```
