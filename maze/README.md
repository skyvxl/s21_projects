# Maze

Язык: Go

Кратко: десктопное приложение для генерации идеальных лабиринтов (алгоритм Эллера), решения и симуляции пещер клеточным автоматом. GUI на Fyne.

Зависимости: Go 1.26+, fyne.io/fyne/v2

Сборка:

```sh
cd src
make
```

Тесты:

```sh
cd src
make tests
```

Структура проекта:

```text
src/
├─ cmd/maze/          # точка входа
├─ internal/
│  ├─ maze/           # модель + формат файлов
│  ├─ eller/          # генерация идеального лабиринта
│  ├─ solver/         # поиск решения
│  ├─ cave/           # клеточный автомат пещер
│  ├─ render/         # отрисовка
│  └─ gui/            # Fyne (вкладки)
├─ examples/          # примеры .txt
├─ Makefile
└─ go.mod
```

Особенности:
- Макс. размер 50×50
- Отрисовка 500×500 px
- Загрузка/сохранение, пошаговая симуляция пещер
