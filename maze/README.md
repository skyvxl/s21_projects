# Maze

Язык: Go

Кратко: генерация идеальных лабиринтов алгоритмом Эллера, поиск пути, обучение агента методом Q-learning и симуляция
пещер клеточным автоматом. Есть десктопный интерфейс на Fyne и веб-интерфейс.

Зависимости: Go 1.26.3+. Для десктопной версии также нужны Fyne (загружается как зависимость Go), C-компилятор для CGO и
системные библиотеки OpenGL.

Запуск десктопной версии из каталога `maze`:

```sh
go run ./cmd/maze
```

Запуск веб-версии:

```sh
go run ./cmd/mazeweb -addr 127.0.0.1:8080
```

Откройте [127.0.0.1:8080](http://127.0.0.1:8080). Примеры файлов лабиринта и пещеры лежат в `examples/`.

Тесты:

```sh
go test ./...
```

Для запуска тестов без графических библиотек используйте `go test -tags ci ./...`.

Структура проекта:

```text
cmd/
├─ maze/          # десктопное приложение
└─ mazeweb/       # веб-сервер
internal/
├─ maze/          # модель и формат лабиринта
├─ eller/         # генератор лабиринтов
├─ solver/        # поиск пути
├─ qlearning/     # обучение агента
├─ cave/          # клеточный автомат для пещер
├─ render/        # отрисовка
├─ gui/           # интерфейс Fyne
└─ web/           # HTTP API и веб-интерфейс
examples/
```
