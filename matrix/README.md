# matrix

Язык: C

Кратко: реализация работы с матрицами (создание, удаление, сумма, вычитание, умножение, транспонирование, детерминант, обратная матрица).

Зависимости: стандартные библиотеки C

Сборка:

```sh
cd src
make
```

Тесты:

```sh
cd src
make test
```

Структура проекта:

```text
src/
├─ functions/      # реализация операций с матрицами
├─ tests/          # unit tests
└─ s21_matrix.h    # заголовочный файл
```
