# matrixplus

Язык: C++

Кратко: объектно-ориентированная реализация матриц с операторами и тестами.

Зависимости: стандартная библиотека C++

Сборка:

```sh
cd src
make
```

Тесты:

```sh
cd src
make test
```

Структура проекта:

```text
src/
├─ s21_matrix_oop.*     # реализация классов и методов
├─ test/                # unit tests
└─ Makefile
```
